# fog-event-detection
Agglomerate Fog Event Detection (AFED) Dataset
The Agglomerate Fog Event Detection (AFED) dataset is designed to aid in the development and evaluation of models for detecting agglomerate fog events. This dataset consists of annotated video clips categorized into three types: Agglomerate Fog Event, Normal Fog Event, and Fog-Free. The dataset includes over 1500 video clips, each lasting 40 seconds.

The videos are captured from highway surveillance cameras across four different locations. For each location, the dataset is organized into subdirectories representing the three different conditions: Agglomerate Fog Event (label 1), Normal Fog Event (label 2), and Fog-Free (label 3). The diversity of environments and conditions makes this dataset particularly valuable for training and testing fog detection models.
